# 売上取り込みと必要人数の提案（自社POC）

最終更新: 2026-07-27
対象: SHISHA Exhale / 星狼 大阪 / 星狼 名古屋

LPが主張している「売上の傾向から必要人数を提案する」を、自社データで成立させるための実装。

---

## 1. 使い方

```bash
# DBに入れず、集計結果と提案人数だけ見る（DBが無くても動く）
npx tsx scripts/import-sales.ts --dry-run

# 1人がさばける売上を変えて試す（店舗ごとの実態に合わせる）
npx tsx scripts/import-sales.ts --dry-run --per-person 25000

# DBへ取り込む
npx tsx scripts/import-sales.ts --org "合同会社データロー"
```

取り込み元:

| 店舗 | ファイル | 形式 |
|---|---|---|
| SHISHA Exhale | `exhale_salary/materials/*/会計明細*.csv`（16ヶ月） | 会計明細 |
| 星狼 大阪 | `accounting/input/sales/ジャーナル履歴_..._2606_星狼大阪.csv` | ジャーナル履歴 |
| 星狼 名古屋 | 同上（星狼名古屋） | ジャーナル履歴 |

## 2. データの実態（2026-07-27 時点）

| 店舗 | 取引 | 営業日 | 期間 | 曜日カーブ（月〜日） |
|---|---|---|---|---|
| SHISHA Exhale | 7,575件 | 483日 | 2025-03〜2026-06 | 37 35 37 39 43 **100** 61 |
| 星狼 大阪 | 187件 | 27日 | 2026-06 のみ | 28 45 42 48 42 62 **100** |
| 星狼 名古屋 | 57件 | 18日 | 2026-06 のみ | 0 36 **100** 56 37 35 39 |

**Exhale だけが判断に足るデータ量。** 土曜が平日の約3倍という傾向がはっきり出る。
星狼2店舗は1ヶ月・取引2桁なので、曜日カーブはノイズ。最低3ヶ月、できれば6ヶ月要る。

売上中央値（1人25,000円を基準にしたとき）:
- Exhale の最も忙しい枠 … 土曜の深夜 68,420円
- Exhale の最も静かな枠 … 月曜の昼 4,400円

15倍の開きがある。時間帯まで分けて人数を決める意味がここに出ている。

## 3. CSVの癖（取り込みで踏んだもの）

Airレジのエクスポートは月によって形が違う。以下は実装で吸収済み。

| 癖 | 例 | 対応 |
|---|---|---|
| 日付のゼロ埋めが月で違う | `2025/3/1` と `2025/05/01` | `normalizeDate()` で揃える |
| 先頭にファイル名だけの行が入る | `2605/会計明細.csv` | `findHeader()` で本当のヘッダーを探す |
| 1会計 = ヘッダー1行 + 明細N行 | 明細行は日付が空 | 日付が入っている行だけを会計として数える |
| 文字コード | Shift_JIS(cp932) | `TextDecoder("shift_jis")` |
| ジャーナル履歴は商品明細行 | 同じ取引が複数行 | 取引Noで畳む |

> 直す前は 2025-03/04 が丸ごと落ちて 6,669件になっていた。修正後は 7,575件で、
> 別途 Python で取った基準集計と一致する。**取り込み件数は必ず基準と突き合わせること。**

## 4. 提案ロジック

`src/lib/business/headcount.ts`

```
1. 曜日 × 時間帯ごとに、過去の売上の「中央値」を取る
2. 「1人がさばける売上」で割って人数にする
3. 店舗ごとの下限・上限で丸める
```

- **平均ではなく中央値**を使う。貸切やイベントが1回入るだけで平常時の目安が跳ね上がるため
  （テストで担保: 100万円の外れ値を1件混ぜても提案人数が変わらないこと）
- 根拠にした営業日が **4日未満の枠は `confidence: "low"`**。UI では注意を出し、鵜呑みにさせない
- 最終決定は店長。提案値は上書きできる前提

### 1人あたり売上（`salesPerPerson`）は店舗ごとに決める

いまの既定 40,000円は仮置き。**この係数だけは実績から決める必要がある**。
Exhale は既定値だと土曜も平日も1〜2人にしかならず、3倍の差が人数に出ない。
25,000円にすると土曜の深夜が3人になり、実感に近づく。

決め方は「土曜の夜は実際に何人で回しているか」を店長に聞いて逆算するのが早い。

## 5. データモデル

```prisma
model StoreSalesDaily {
  storeId       String
  businessDate  String   // 営業日（店舗の切替時刻を適用済み）
  slotId        String?  // 時間帯。null は日合計 or 時間帯に割り当てられなかったぶん
  amount        Int
  customerCount Int?
  source        String   // CSV_AIRREGI / MANUAL
  @@unique([storeId, businessDate, slotId])
}
```

営業日は店舗の切替時刻で判定する（Exhale は 5:00、星狼は 6:00）。
深夜0〜5時の来店は前日の営業日に寄る。
