# みせ勤 ユーザー向け仕様書

## 概要

**みせ勤**は、店舗スタッフの勤怠管理を行うWebアプリケーションです。管理者はブラウザから勤怠を管理し、スタッフは店舗に設置した端末（タブレット・PCなど）から専用URLにアクセスして打刻します。スタッフ側はアカウント登録不要で利用できます。

---

## 1. 登場人物（ロール）

| ロール | 説明 |
|--------|------|
| **オーナー (OWNER)** | 組織の最上位管理者。組織設定・管理者追加・削除ができる |
| **管理者 (ADMIN)** | 店舗の日常管理を行う。スタッフ管理・勤怠管理・閉め処理など。特定店舗のみに権限を絞ることも可能 |
| **スタッフ** | 打刻URLから打刻を行う。管理者から招待された場合はログインして自分の勤怠閲覧・修正申請が可能 |

---

## 2. 管理者向け機能

### 2-1. アカウント・組織のセットアップ

#### 新規登録
1. `/register` からメールアドレス・パスワード・お名前を入力して登録
2. 確認メールが届くのでリンクをクリックして認証
3. 認証後、オンボーディング画面で**組織名**と**最初の店舗名**を入力してセットアップ完了

#### ログイン
- `/login` からメールアドレス・パスワードでログイン
- パスワードを忘れた場合は「パスワードを忘れた方」から再設定

---

### 2-2. ダッシュボード

ログイン後のトップページ。本日の勤怠状況をひと目で確認できます。

- **在勤中スタッフ数** — 現在出勤中のスタッフ数
- **打刻異常件数** — 退勤忘れ・長時間労働など異常が検出された件数
- **修正申請件数** — スタッフからの承認待ち修正申請数
- **今日の勤怠一覧** — スタッフ別・店舗別の出退勤時刻と状態

---

### 2-3. スタッフ管理

#### スタッフの追加
1. `スタッフ一覧 > スタッフを追加` から登録
2. 必須項目: **表示名**（打刻画面に表示される名前）
3. 任意項目: 氏名・メールアドレス・電話番号・社員コード・入社日・所属店舗

所属店舗を選択すると追加と同時に打刻可能になります。

#### 招待メールの送信
- スタッフ詳細ページの「招待メールを送る」ボタンから招待メールを送信
- スタッフはメールのリンクからアカウント登録し、自分の勤怠確認・修正申請が可能になります
- メールアドレス未登録のスタッフには招待メールを送れません

#### スタッフの在籍状態
| 状態 | 説明 |
|------|------|
| 在籍 (ACTIVE) | 通常の在籍中 |
| 招待中 (INVITED) | 招待メール送信済み・未承認 |
| 休職中 (ON_LEAVE) | 一時的な休職 |
| 停止中 (SUSPENDED) | 打刻・ログインを一時停止 |
| 退職 (RESIGNED) | 退職済み。退職日が記録される |

スタッフ詳細ページの「在籍状態」セクションからステータスを変更できます。

#### 所属店舗の管理
- スタッフ詳細の「所属店舗」セクションから店舗を追加
- 各店舗に対して以下を設定できます:
  - **主担当**: 主な所属店舗
  - **打刻可**: この店舗での打刻を許可するか
  - **開始日 / 終了日**: 所属期間

#### PIN管理
スタッフ詳細の「PIN管理」セクションから設定します。

- **PIN設定**: 4〜8桁の数字を設定。スタッフが打刻URLでPINを入力して本人確認します
- **PIN削除**: 設定済みのPINを削除
- **PIN必須**: OFFにすると、PINなしで打刻できます（共有端末での簡易打刻向け）
- PINを5回連続で間違えると15分間ロックされます

#### 時給管理
- スタッフ詳細の「時給履歴」セクションから確認
- 新しい時給は有効開始日を指定して追加します（前の時給は自動的に終了日が設定されます）

---

### 2-4. 店舗管理

#### 店舗の追加
`店舗一覧 > 店舗を追加` から店舗名を入力して追加。作成と同時に打刻URLが生成されます。

#### 店舗設定
| 設定項目 | 説明 |
|----------|------|
| 店舗名 | 表示用の名称 |
| 店舗コード | 任意の管理コード |
| 住所 | 店舗の住所 |
| タイムゾーン | 初期値: Asia/Tokyo |
| 日付変わり時刻 | この時刻以前の打刻は前日の営業日として扱う（例: 06:00設定→深夜3時の打刻は前日扱い） |

#### 打刻URL（クロックURL）の管理
- 店舗詳細ページで打刻URLを確認・再生成できます
- URLを店舗の端末でブックマークしてご利用ください
- **再生成**すると旧URLは無効になります
- **有効期限**（任意）を設定することもできます

---

### 2-5. 勤怠管理

#### 勤怠一覧
`勤怠一覧` から日付・店舗・スタッフ・状態でフィルタリングして勤怠を確認できます。

#### 勤怠の状態
| 状態 | 説明 |
|------|------|
| 勤務中 (IN_PROGRESS) | 出勤中（退勤前） |
| 完了 (COMPLETED) | 正常に退勤済み |
| 退勤未打刻 (MISSING_CLOCK_OUT) | 退勤打刻がない |
| 休憩未終了 (MISSING_BREAK_END) | 休憩終了打刻がない |
| 異常 (ANOMALY) | その他の異常（長時間労働など） |

#### 異常検出の種類
| 異常 | 条件 |
|------|------|
| 退勤未打刻 | 24時間以上退勤なし |
| 休憩未終了 | 休憩開始後に休憩終了なし |
| 長時間労働 | 12時間以上の勤務 |
| 退勤前に出勤 | 時刻の前後矛盾 |
| 重複出勤 | 同日に複数の出勤打刻 |
| 複数店舗重複 | 同時間帯に別店舗で打刻 |

#### 勤怠の修正（管理者）
1. 勤怠詳細 > 「修正する」から修正フォームを開く
2. 出勤時刻・退勤時刻・休憩時間を修正
3. 修正理由を入力して保存
4. 修正前・後の記録は監査ログに保存されます

> **注意**: 締め処理済みの勤怠は修正できません

#### 勤怠の追加（管理者・打刻漏れの代行）
その日の記録がまったく無い「打刻漏れ」は、スタッフの付け忘れ申請を待たずに管理者が直接登録できます。
1. 勤怠一覧 > 右上の「勤怠を追加」
2. 店舗・スタッフ・出勤時刻・退勤時刻（・休憩）を入力
3. 登録理由を入力して保存（修正履歴と監査ログに残ります）

- 営業日は出勤時刻と店舗の日付切替時刻から自動で決まります（打刻と同じ規則。切替前の深夜出勤は前日の営業日）
- 同じ営業日に勤怠が既にある場合は登録できません。「修正する」で直してください
- 締め処理済みの期間には登録できません
- 退勤だけ忘れた場合は、この機能ではなく「勤怠の修正」を使います

#### 退勤メモ
スタッフが退勤時に申し送り事項をメモとして残せます。管理者は勤怠詳細ページの「退勤メモ」セクションで確認できます。

---

### 2-6. 修正申請（スタッフ→管理者）

スタッフ（ログインユーザー）は自分の勤怠に対して修正を申請できます。

1. スタッフがマイページから「修正申請」を送信
2. 管理者が `修正申請一覧` から内容を確認
3. 承認（勤怠を修正）または却下を選択
4. 申請にコメントを付けることも可能

---

### 2-7. 閉め処理

指定した期間の勤怠を「締め済み」にします。締め後は管理者も修正できません。

1. `閉め処理 > 新しい閉め期間を作成` から期間を指定
2. 対象期間を確認し、「閉める」を実行
3. 締め済み勤怠には「締め済み（修正不可）」と表示

---

### 2-8. CSV エクスポート

`エクスポート` から勤怠データをCSVでダウンロードできます。

- 期間・店舗・スタッフを指定してフィルタリング
- 出力項目: スタッフ名、社員コード、店舗名、勤務日、出勤時刻、退勤時刻、休憩時間、実労働時間、状態

---

### 2-9. 管理者メンバー管理

`管理者設定` から組織の管理者を追加・削除できます（オーナーのみ）。

- 追加: 既存アカウントのメールアドレスを入力して追加
- 削除: 管理者一覧から「削除」で無効化
- オーナーは最低1名必要です（自分を削除することはできません）

#### 店舗スコープの設定
管理者に特定店舗のみへのアクセスを制限できます。スコープ未設定の場合は全店舗にアクセス可能です。

---

### 2-10. 組織設定

`組織設定` から組織全体の設定を変更できます（オーナーのみ）。

- 組織名
- タイムゾーン（デフォルト: Asia/Tokyo）
- 日付変わり時刻（デフォルト: 06:00）

---

### 2-11. APIキー管理

外部システム連携用のAPIキーを発行できます。

1. `APIキー管理 > 新しいAPIキーを生成` から作成
2. キー名・説明・店舗スコープを設定
3. 生成されたキーは一度のみ表示されます（必ず控えてください）
4. 不要になったキーは「無効化」で即時失効

---

### 2-12. 監査ログ

`監査ログ` からシステム上の全操作履歴を確認できます。管理者の操作・スタッフの打刻・APIアクセスなどすべてが記録されています。

---

## 3. スタッフ向け打刻機能

### 3-1. 打刻の流れ

1. 店舗端末でブラウザを開き、管理者から教えてもらった打刻URLにアクセス
2. 自分の名前を選択
3. PINを入力（PIN必須設定がOFFの場合はスキップ）
4. 打刻ボタンをタップ

### 3-2. 打刻の種類

| ボタン | 説明 |
|--------|------|
| **出勤** | 出勤開始 |
| **休憩開始** | 休憩に入る |
| **休憩終了** | 休憩から戻る |
| **退勤** | 退勤（メモを残すことができます） |

### 3-3. 打刻状態の遷移

```
[出勤前] → 出勤 → [勤務中] → 休憩開始 → [休憩中] → 休憩終了 → [勤務中] → 退勤 → [退勤済み]
```

- 休憩中に退勤ボタンを押すと、確認ダイアログが表示されます（休憩が自動的に終了します）
- 当日の退勤が完了した後は、同日に再度出勤することはできません

### 3-4. 退勤時のメモ

退勤ボタンを押すとメモ入力画面が表示されます。申し送り事項があれば任意で入力できます（500文字まで）。

### 3-5. スタッフのマイページ（ログインユーザー）

招待を受けてアカウントを作成したスタッフは管理画面にログインできます。

- **マイ勤怠** — 自分の勤怠履歴の確認
- **マイ修正申請** — 修正申請の送信・確認
- **マイ店舗** — 所属店舗の確認

---

## 4. よくある質問

**Q: 退勤を押し忘れました**
A: 管理者に連絡し、管理画面から勤怠を修正してもらうか、マイページから修正申請を送ってください。

**Q: PINを忘れました**
A: 管理者に連絡してPINをリセットしてもらってください。

**Q: 打刻URLにアクセスできません**
A: URLが無効になっている可能性があります。管理者に打刻URLを確認してもらってください。

**Q: 管理者パスワードを忘れました**
A: ログイン画面の「パスワードを忘れた方」から再設定できます。
