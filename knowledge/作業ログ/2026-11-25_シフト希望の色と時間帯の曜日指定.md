# シフト希望の「希望」の色と、時間帯の曜日指定

**日付**: 2026-11-25 ／ **依頼**: 高野（台帳 #1545、VLL） ／ **ブランチ**: `fix/shift-preferred-color-weekday`（`9082dfa`、main へ `--no-ff` マージ・本番反映済み 2026-11-25）

## きっかけ

VLL は12月分のシフト提出からみせ勤を使っている。キャストの希望画面で次の2点が出た。

1. 「希望」ボタンが薄いピンクで「不可」の赤と見分けにくい。業態テーマ（`src/lib/verticals/themes.ts`）の primary がピンク（#BE4285）なのが原因
2. 平日（例 11/19 木）にも土日祝の時間帯が並ぶ。`ShiftSlot` に曜日の項目が無かった

本番の VLiverLab東京池袋店の時間帯（2026-11-25 読み取り）: 平日 19:00-22:00 / 土日祝(前半) 17:00-20:00 / 土日祝(後半) 20:00-23:00（有効分）。

## 決めたこと

- 「希望」は業態テーマに依らない固定の青（blue-600 系）。管理側のシフト作成画面のセル背景・凡例も同じ青系（blue-50）にそろえた
- `ShiftSlot.daysOfWeek Int[]`（0=日〜6=土、7=祝日、空=毎日）を足した。名前の規約（「平日」「土日祝」を名前から読む）は、店が名前を変えた瞬間に黙って壊れるので採らなかった
- **祝日は曜日より優先し、「祝」を含む時間帯だけを出す。** 月曜の祝日には平日の時間帯が消え、土日祝の時間帯が出る。祝日の判定は `@holiday-jp/holiday_jp`（2050年分まで同梱、サーバー専用）
- 効かせた場所: キャストの希望画面（その日に出る時間帯だけ並べる）/ 希望の提出（対象外の日は拒否）/ シフト作成画面（対象外の日は「対象外」でセルを潰す。既にあるシフトは消せるよう残す）/ 自動生成（対象外の日の必要人数を無視）
- 曜日は店舗詳細の「シフトの時間帯」で時間帯ごとに選ぶ。既存の時間帯は空＝毎日なので、設定するまで挙動は変わらない

## 残したこと

- 「営業時間の文章から時間帯を作る」（AI 読み取り → `replaceShiftSlots`）は曜日を作らない。これで作り直すと曜日が空（毎日）に戻る
- シフト管理画面の「希望提出率」は日数を7日で割ったまま（曜日指定を考慮していない）

## 本番反映（2026-11-25、高野承認）

- 本番は `feature/daily-report`（main 未マージ・12コミット）の版で動いていたので、**main＋修正だけを出すと日報・再出勤が消える**。一時 worktree で `feature/daily-report`（`321d04e`）に修正をマージした `e180864`（ローカルブランチ `deploy/20261125-shiftpref`）からイメージを作った。main にはこの修正だけを入れた
- 衝突は `migrations.sql`（両側の末尾追記。両方残し、曜日を最後に）と生成物 `class.ts`（`prisma generate` で作り直し）。型エラー0・テスト250件通過
- バックアップ `/home/ubuntu/backups/misekin/misekin-20261125-pre-shiftpref.sql.gz` → ローカル build `misekin-app:shiftpref-20261125`（`.env` なし）→ `docker save | gzip | ssh docker load`（18秒）→ `latest` に付け替え → `up -d --no-build --no-deps app`。available 549MB。サーバー上ではビルドしていない
- 起動時の migrations.sql: `shift_slots."daysOfWeek"` integer[] NOT NULL DEFAULT '{}' ができた。エラーは既存の89行目だけ。`/login` 200 / `/my-shifts` 307 / API キーなし 401
- VLiverLab東京池袋店の時間帯を DB から設定（監査ログ actorType SYSTEM・action `SHIFT_SLOT_UPDATE`・理由つき）。前はすべて `{}`。後: 平日 `{1,2,3,4,5}` / 土日祝(前半)・(後半) `{0,6,7}`
- 画面の確認: 本番DBのコピーを一時 Postgres に入れ、同じイメージをローカルで起動し、VLLのキャスト1人のセッションで `/my-shifts` の HTML を取得。37日のうち月〜金27日は「平日」だけ、土日10日は「土日祝(前半)(後半)」だけ。希望ボタンは `border-blue-300`（47個＝27＋10×2）で primary は0。コピーと一時コンテナは確認後に消した
- 戻すとき: `docker tag misekin-app:dailyreport-loc-20261122 misekin-app:latest` → `up -d --no-build --no-deps app`。旧コードは `daysOfWeek` を読まないのでそのまま動く（列は残る）
